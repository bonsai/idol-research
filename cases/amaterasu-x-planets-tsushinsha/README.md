# アマレテラス × 惑星通信社

## Research Case

アマレテラスと惑星通信社を、idol-research における**楕円の二点**として置き、その間に存在する活動・主体・媒体・関係を観測する。

## Research Model

```text
        アマレテラス
             ●
          ╱     ╲
       ╱           ╲
      │   research  │
       ╲           ╱
          ╲     ╱
             ●
        惑星通信社
```

二点を単純比較して優劣を決めるのではなく、二点の間に何が存在するかを研究対象とする。

## Source

`idol-db` を canonical data / provenance の正本として参照する。

研究データをここで複製して新しい正本を作らない。

## Principle

このケースでは最初から仮説を固定しない。

**二点を置く → 間を観測する → 問いを生成する。**
