# Terasuma case

First empirical case for `idol-research`.

## Research focus

`はいどーも！テラスマです！`を、アイドル×お笑いという境界領域の事例として観測する。

The case is used to test hypotheses; it is not the definition of the entire research domain.

## Initial hypothesis set

- H1: お笑い活動は差別化要因として機能する
- H2: お笑い活動は異なる接触経路／ファン層を生む
- H3: アイドル活動とお笑い活動の往復がメンバーのキャラクター形成に影響する
- H4: ライブが複数文化を接続する場として機能する
- H5: この構造が他のアイドル事例でも観測される

## Loop

Observation → Question → Hypothesis → Data → Analysis → Evaluation → Insight → Next Hypothesis
