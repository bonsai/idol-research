# Terasuma case

`はいどーも！テラスマです！` を最初の実証ケースとして扱う。

ここでは個別ファンサイトではなく、マーケティング／データサイエンスの観点から観測する。

## Questions

- アイドル活動とお笑い活動の往復は差別化要因になるか
- お笑い接点は新規認知・初回接触に寄与するか
- ライブ／SNS／メディア接点から継続参加までの導線はどうなるか
- メンバー個人の活動差はファン形成にどう影響するか

## Hypothesis

H0: テラスマは「アイドル×お笑い」の単純な融合ではなく、両者の境界を活動領域にしている。

H1: お笑い活動は認知・差別化に寄与する。

H2: お笑い接点とアイドル接点では流入する観客層に差がある。

H3: アイドル活動とお笑い活動の往復がメンバーのキャラクター形成に影響する。

## Loop

Observation → Question → Hypothesis → Data → Analysis → Evaluation → Insight → Next Hypothesis
